Record Shapes Through the Pipeline

The 18-field ECU tick is never read whole at the edge — Beam's windows collapse it to five fields per minute, Redis holds six for sub-millisecond reads, and the browser receives a fan-in of blobs. Only raw history keeps every byte, landing in Cassandra unchanged.
